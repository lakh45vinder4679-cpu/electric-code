    Electric Code Assistant

    Ultra-lightweight AI web IDE - optimized for 2GB RAM devices.

    Developed by Electric Code Assistant | Created by Lakhvinder Singh

    • Deep dark-mode, glassmorphism UI inspired by Gemini / Cloud Code
    • Vanilla JS + pure CSS3 - zero heavy frameworks
    • Multi-model routing: Groq / NVIDIA (UI speed), DeepSeek / Gemini (logic & debugging), OpenRouter / Julelum (fallback)
    • Live Search integration for real-time data apps
    • Encrypted local key storage with AES-GCM
    • Auto-save to localStorage - no data loss on low-end devices
    • Modular HTML/CSS/JS export - instantly APK-ready for WebView
